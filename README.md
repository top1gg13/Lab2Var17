# Lab2Var17 — проверка и поиск времени UTC

Лабораторная работа по регулярным выражениям, вариант 17:
проверка и поиск синтаксически корректного времени в формате UTC.

## Формат

ГГГГ-ММ-ДДTЧЧ:ММ:ССZ — например, `2026-11-13T16:38:00Z`

Месяц 01–12, день 01–31, час 00–23, минуты и секунды 00–59, `Z` — время UTC. Буквы `T` и `Z` можно писать и строчными (`t`, `z`).

## Запуск

    pip install requests
    python main.py

Меню: 1 — проверить строку, 2 — найти во введённом тексте,
3 — найти в файле, 4 — найти на веб-странице, 0 — выход.
